## 要件

- PHP,SQLで作る
- ログイン機能あり

## これから実装するもの
1週目：基本機能を動かす
| 日       | やること             | 到達目標               |
| ------- | ---------------- | ------------------ |
| **1日目** | 設計確認・DB作成・フォルダ構成 | users/tasksテーブルを作成 |
| **2日目** | トップ・ユーザ登録        | ユーザをDBに登録できる       |
| **3日目** | ログイン・ログアウト       | セッションを使ってログインできる   |
| **4日目** | タスク登録            | ログインユーザのタスクを登録できる  |
| **5日目** | タスク一覧            | 自分のタスクだけ一覧表示できる    |
| **6日目** | タスク編集・完了/未完了     | タスクを更新できる          |
| **7日目** | タスク削除・1週目の修正     | CRUDを一通り完成         |

2週目：実用機能・品質を上げる
| 日        | やること         | 到達目標                    |
| -------- | ------------ | ----------------------- |
| **8日目**  | ユーザ情報・マイページ  | ユーザ情報を表示・編集できる          |
| **9日目**  | 検索・絞り込み      | タスクを条件検索できる             |
| **10日目** | ソート・ページング    | 最大10件表示＋ページ移動           |
| **11日目** | バリデーション      | 必須・文字数・形式などをチェック        |
| **12日目** | セキュリティ対策     | SQLインジェクション・XSS・認証チェック等 |
| **13日目** | 画面調整・エラー処理   | 操作の流れを整える               |
| **14日目** | テスト・バグ修正・仕上げ | 一通り正常に使える状態             |
