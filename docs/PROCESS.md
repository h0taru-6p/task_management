##　処理の設計
### ユーザ登録処理
1. 入力フォームから ユーザ名, メールアドレス, パスワードを受け取る
2. 確認ボタン押下で、入力値のチェック
3. 問題があれば、フォーム画面再表示（入力は残す）
4. 問題がなければ、入力内容確認画面へ
5. 確認画面の修正ボタン押下で、フォーム画面に戻る
6. 確認画面の登録ボタン押下で、DBにinsert
7. ログイン画面にリダイレクト

### ユーザ編集処理
1. DBから保存されている　ユーザ名, メールアドレスを受け取り表示（パスワードは非表示）
2. 変更ボタン押下で、入力値のチェック
3. 問題があれば、フォーム画面再表示（入力は残す）
4. 問題がなければ、DBにupdate（空のフォームは更新しない）

### ログイン処理
1. 入力フォームから メールアドレス, パスワードを受け取る
2. 入力値の照合
3. 問題があれば、フォーム画面再表示
4. 問題がなければ、セッションにuserのid保存
5. タスク一覧画面にリダイレクト

### ログアウト処理
1. セッションやクッキーの内容を削除, 上書き
2. トップ画面にリダイレクト

### タスク登録処理
1. 入力フォームから タイトル, 説明文, 期限日を受け取る
2. 入力値のチェック
3. 問題があれば、フォーム画面再表示（入力は残す）
4. 問題がなければ、DBにinsert
5. タスク一覧画面にリダイレクト

### タスク編集処理
1. DBから保存されている タイトル, 説明文, 期限日, 完了/未完了を受け取る
2. 入力値のチェック
3. 問題があれば、フォーム画面再表示（入力は残す）
4. 問題がなければ、DBにupdate
5. タスク一覧画面にリダイレクト

### タスク削除処理
1. DBから保存されている タイトル, 説明文, 期限日, 完了/未完了を受け取る
2. DBからdelete
3. タスク一覧画面にリダイレクト

### 検索・絞り込み処理
1. 入力フォームから検索・絞り込みの文字列を受け取る
2. 受け取った文字列でDBにてlike検索
3. ヒットしたタスクをリダイレクト表示
4. 空文字検索の場合は、全件検索でリダイレクト表示
