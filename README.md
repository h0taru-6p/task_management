## 動作環境
- Windows
- XAMPP
- Apache
- PHP:8.2.12
- MariaDB:10.4.32

## 環境構築
- XAMPPをインストール
- 本リポジトリをhtdocsに配置
- ApacheとMySQLを起動(XAMPP Control Panel)
- phpMyAdminを開く(http://localhost/phpmyadmin/)
- DB名"task"を作成
- SQLファイルのインポート(database/sample.sql)
- http://localhost/task_management/ にアクセス

## 操作方法

### 1. ユーザー登録

1. トップ画面から「ユーザー登録」を選択
2. ユーザー名、メールアドレス、パスワードを入力
3. 「登録」ボタンを押す

### 2. ログイン

1. 登録したメールアドレスとパスワードを入力
2. 「ログイン」ボタンを押す
3. タスク一覧画面が表示される

### 3. タスク登録

1. 「タスク登録」を選択
2. タイトル、内容などを入力
3. 「登録」ボタンを押す

### 4. タスク編集

1. タスク一覧から編集したいタスクを選択
2. 内容を変更
3. 「更新」ボタンを押す

### 5. タスク削除

1. 削除したいタスクの「削除」を選択
2. 確認モーダルが表示される
3. 「削除」を選択

### 6. タスク検索・並び替え

1. 検索欄にキーワードを入力
2. 必要に応じて並び順を選択
3. 「検索」ボタンを押す

## 工夫した点
- SQLインジェクション対策としてプリペアドステートメントを使用
- XSS対策として出力時にhtmlspecialcharsを使用
- 不正アクセス対策としてログインチェックを各画面に関数として配置
- JavaScriptを使用して削除確認モーダルを実装
- セッションを利用して処理結果をトースト通知
- 発想力への刺激目的でタスクカード表示[Auto]の伸縮性採用
